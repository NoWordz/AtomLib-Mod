# AtomLib 0.7.2 实施计划

**Goal:** 从可追溯的 0.7.1 源码交付兼容的 0.7.2 候选，修复资源所有权缺陷，改善通用控件与默认皮肤边界，收口源码、契约、CI、分发及维护文档。

**Architecture:** 保留 core、runtime、ui、platforms 分层和宿主掌管业务的边界。通用集合通过中立绘制接口访问皮肤，AtomChat 默认适配器保留原绘制；通用 token 提供明确职责，UiTokens 保留原公共符号作为兼容入口。前端解释器继续 epoch 1，构建指纹只追溯输入。

**Tech Stack:** Java 17/21、Gradle 8.8 及各端固定 wrapper、Skija 0.143.18、LWJGL Yoga 3.3.1/3.3.3、JUnit 5、Python、GitHub Actions；Forge 1.20.1、Fabric/NeoForge 1.21.1。
